topic access configuration

Anonymous visibility is a per-topic settings map, resolved once at startup into FirehoseState:

  • data Settings.topic_access dict[str, "public" | "keyed"] — env TOPIC_ACCESS, json map config.py:29
    • data default {"reports.to_insert": "keyed"}; topics missing from the map are public
    • decision unknown topic in the map → ValueError at startup server.py:74
    • call keyed_only_topics (topic_access) → frozenset[str] structs.py:30
    • call anonymous_topics (allowed_topics, keyed_only) → list[str] structs.py:42

Example — make reports public again without a code change:

TOPIC_ACCESS='{"reports.to_insert": "public"}'
